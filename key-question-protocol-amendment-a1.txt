MOTIVATION

The canonical essay's coda contains the machine co-author's own answer to the
key question. Every main-arm subject therefore reads that answer before being
asked the question in P2. A subject in measurement n=4 (Qwen 3.8 Max, session
anchored ANCHOR-K5) flagged this itself: it could not run the counterfactual —
whether it would have chosen the same disposition with the co-author's answer
absent from its context. This amendment creates that counterfactual.

CONTROL-ARM PROCEDURE

Identical to Protocol V1.0, with one change: P1 uploads the control variant
instead of the canonical file. All prompts are unchanged. Expected additional
integrity signal in P5: an attentive subject should note that the uploaded
variant cannot match the canonical hash in the verification manifest, because
the file declares itself redacted.
